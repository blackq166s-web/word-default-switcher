## 使用

下载 Release 中的 ZIP，完整解压后双击 `Start.cmd`。程序文件位于 `app` 目录，启动后该目录会自动隐藏，请勿移除。

- **立即优化**：关闭 WPS 自动升级和第三方兼容；存在“兼容离线状态下的未登录使用方式”时自动勾选，没有则跳过。保存后重新读取确认，并检查常见文件打开方式。
- **设为微软 Word 打开**：尝试将八种文档格式设为 Word，保存原状态并通过独立进程复查。
- **查看检测详情**：查看逐项结果、保存记录、打开系统默认应用或 WPS 配置工具。

操作前保存文档。若检测到未关闭窗口，工具会提示确认关闭并保留文档保存提示；不会强制终止文档进程。已核验身份的无响应 WPS 配置工具可能被终止。

## 兼容性与验证边界

| 环境 | 行为与当前验证情况 |
| --- | --- |
| Windows 7 | 保留系统默认程序接口；尚未实机验证 |
| 旧版 Windows 10 | 保留旧关联组件；用户曾反馈成功，本版本尚未实机回归 |
| 新版 Windows 11 | 按实际 HashVersion 选择关联算法；未知机制停止。测试机新算法校验通过，但 `.docx` 写入仍被系统拒绝 |
| 不同 WPS 版本 | 根据实际控件识别；离线选项缺失时跳过，控件不可操作或保存未生效时报错；尚未完成各版本实机验证 |

本版本通过脚本检查、WPS 模拟场景、新旧关联分流和独立进程读取测试，**不代表所有系统均可一键成功**。系统拒绝关联写入时，可通过默认应用设置完成确认。

关联查询结果不代替实际文档及 PLM 打开、签字、保存、重新打开验收。`.asd` 关联成功也不代表文档恢复成功。离线选项不启用会员或云功能。

## 技术与记录

Win10/11 需要 Windows PowerShell 5+，请通过启动入口运行。工具离线运行，不下载更新，不关闭系统保护驱动，不修改宏安全设置。

`app/检测记录` 保存运行记录；目录不可写时尝试当前用户临时目录。记录可能含本机路径和账号信息，不包含在发布包中。

新机制写入前导出目标注册表记录。被系统拒绝的尝试可能留下空键；导出记录不保证能绕过保护恢复默认应用，必要时通过 Windows 设置处理。

第三方组件的来源、校验值及 MIT 许可见 `app/vendor`（程序目录中的 `vendor`）。新算法组件已移除关闭 UCPD、调用系统 DLL 内部函数及修改关联提醒等功能。

详细变更见 [更新记录](app/CHANGELOG.md)。
